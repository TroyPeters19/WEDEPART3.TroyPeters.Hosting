Project Overview

This project is a website proposal for the National Council of SPCAs (NSPCA), a South African organisation that works to prevent animal cruelty and promote animal welfare.

The purpose of the website is to give visitors clear information about the NSPCA, animal welfare and ways that the public can support animal welfare. The website will also make it easier for people to find information about reporting animal cruelty.

The website will be kept simple and easy to navigate so that visitors can quickly find the information they need. It will be developed using basic HTML, CSS and JavaScript.

Website Goals and Objectives

The main goals of the website are:

Explain what the NSPCA is and what it does.

Provide useful information about animal welfare.

Encourage people to support their local SPCAs.

Provide information about volunteering and ways to get involved.

Provide an easy way to report animal cruelty.

Make important information easy to find.

Create a website that is simple and user-friendly.

Key Features and Functionality

The planned website will include:

A navigation menu available across all pages.

A homepage with an introduction to the NSPCA.

An About Us page with information about the organisation.

A Welfare page with animal welfare information.

A Services page with information about support and involvement.

A Contact Us page with contact information and a contact form.

Images related to animals and animal welfare.

Links to useful NSPCA information.

A form for visitors to submit enquiries.

Clear buttons and links for important actions.

Basic JavaScript for form validation and simple interactive features.

Timeline and Milestones

Week 1

Research the NSPCA and collect suitable content

Week 2

Complete the project proposal and website planning

Week 3

Create the sitemap and file structure

Week 4

Create the HTML pages

Week 5

Add CSS styling and page layouts

Week 6

Add JavaScript and form functionality

Week 7

Test the website and fix errors

Week 8

Finalise the website and prepare the submission

Part 1 Details

Part 1 focuses on planning and research for the NSPCA website.

This includes:

Selecting the NSPCA as the target organisation.

Researching the organisation and animal welfare.

Identifying the target audience.

Defining the website goals and objectives.

Planning the website pages and features.

Creating the sitemap.

Planning the file and folder structure.

Creating low-fidelity wireframes.

Identifying technical requirements.

Planning the project timeline and budget.

Recording relevant references.

Parts 2 and 3 will focus on developing and improving the website in later submissions.
